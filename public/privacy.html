Autonomous Game Lab Privacy Policy

Last updated: 2026-05-25

Autonomous Game Lab collects anonymous gameplay events to improve game balance, onboarding, and replay quality. Accounts, paid purchases, and advertising are disabled until production gates pass.

Data We Collect

We collect anonymous gameplay analytics, including events such as game viewed, game started, tutorial completed, turn taken, level completed, game abandoned, and experiment assignment. These events help improve onboarding, balance, replay quality, and production readiness.

Data We Do Not Collect Yet

We do not require accounts, contact information, precise location, payment data, user-generated content, or real-money prizes in the current release.

Analytics Providers

Local development stores analytics in the browser and optional local export files. If production analytics are configured, anonymous gameplay events may be forwarded to PostHog or the first-party event collector unless external analytics is disabled in the app.

User Controls

The app includes an external analytics opt-out control. Local browser analytics can also be cleared by clearing site data for this app.

Monetization

Ads, purchases, subscriptions, and paywalled core rules are disabled until retention, privacy, and platform policy gates pass.

Contact

This bootstrapped project still needs a production support address before public app-store submission.
